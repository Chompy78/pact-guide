# OPEN-QUESTIONS.md

## How AI should use this file

This tracks unresolved design questions. Leave `Decision` blank until the
question is actually resolved. Never delete a question, even once it is
resolved — mark it resolved by filling in `Decision` with the relevant
`D-YYYY-MM-DD-slug` ID from `DECISIONS.md`. When adding a new question, make
it specific enough that a single playtest session could plausibly answer it.

> Note: the `Linked Task` field points at a task in `TASK_BOARD.md` by title.
> Tasks no longer carry stable D-xxx IDs (see D-2026-07-17-adopt-standard-file-shapes
> in `DECISIONS.md`), so the link is by name.

## IDs

Format: `Q-001`, `Q-002`, `Q-003`, …. IDs are never reused.
