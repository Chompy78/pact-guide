# PACT Rules & Player Guide

PACT is a homebrew tabletop RPG system built around a single idea: **everything your character
is — levels, class features, spells, skills — is bought with one currency (AP)**. Your level is
just how many Hit Dice you own. This repo is the public home of the system's Player's Guide and
the design reasoning behind it.

## Read the guide

**[PACT Players Guide](PACT-Players-Guide.html)** — the complete current guide, one
self-contained HTML file. Download it or read it via the project's GitHub Pages site.

## Playing in a PACT game? Take the survey

**[Player survey](survey/)** — about five minutes, covering character creation, spending AP,
spellcasting, and how the campaign's feeling. Responses go privately to the DM (via Formspree);
nothing you write appears in this repo.

## The design reasoning, in the open

These aren't marketing copies — they're working snapshots of the actual design-decision files
this project runs on, refreshed periodically from the private working repo:

- **[DECISIONS.md](DECISIONS.md)** — every design decision made so far, with the options
  considered and the reasoning, in a structured append-only log.
- **[OPEN-QUESTIONS.md](OPEN-QUESTIONS.md)** — the questions currently *unresolved*, waiting on
  playtest evidence (character-creation friction, spellcasting clarity, AP-budget feel).
- **[TASK_BOARD.md](TASK_BOARD.md)** — what's actively being worked on and what's queued.

What you *won't* find here: playtest evidence files or session notes. Those record real feedback
from real players at a private table, given to the DM in confidence — publishing them isn't the
DM's call to make unilaterally, so they stay in the private working repo.

## Want to help?

- **Found a rough spot, an ambiguity, or a rules hole?** Open an
  [Issue](../../issues) — the open questions above are exactly the kind of thing playtest
  reports move forward.
- **Want to talk design?** Start a [Discussion](../../discussions).
- **Spotted a typo or unclear wording?** PRs against the guide are welcome.
